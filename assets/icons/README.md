# Weather icon sets

Used by `pixelgrid/activities/weather_icons.py`. Pick one with `activities.weather.icon_set` (now screen),
`hour_icon_set` or `forecast_icon_set`.

- `twemoji/`: Twemoji 14.0.2, 72x72 PNGs, downscaled at load time.
  Copyright Twitter, Inc. and other contributors. Graphics licensed under CC-BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Source: https://github.com/twitter/twemoji
- `lbc/`: "unicornhat_weather_icons" by LoveBootCaptain, MIT license (see `lbc/LICENSE`).
  Animated sprite strips: `HD/` has 16x16 frames, `SD/` has 8x8 frames.
  Source: https://github.com/LoveBootCaptain/unicornhat_weather_icons
- `pixel`: hand-drawn 9x9 icons that live in the code (`weather_icons.PIXEL_ART`), no files.
